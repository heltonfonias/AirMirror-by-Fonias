AirMirror by Fonias unifies the UxPlay receiver, controller, settings, and tray menu in one Windows app. This release adds a detailed guide, automatic update checks, a verified one-click installer download, and versioned GitHub releases.

Download the MSI for a regular Windows installation or the portable ZIP for manual extraction. AirMirror uses Bonjour for local discovery and may request administrator approval to install the service or an update.
